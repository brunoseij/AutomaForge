ESTADO DA PARTIDA

Dados conhecidos

Estado estruturado e correção manual

Somente dados públicos. Edite entidades, lotes por tipo/quantidade/local, grupos, casas e níveis. Vazio exige occupancy_known=true; oclusão exige status=unknown. A revisão protege os dados de substituições visuais automáticas. IDs devem permanecer estáveis.

Candidatos não substituem entidades existentes. Conflitos devem ser corrigidos no editor antes de confirmar.

DISPOSITIVO NO TRIPÉ

Observação do tabuleiro

Posicione a câmera acima do tabuleiro. Não é necessário reposicionar o tripé para ler cartas privadas; use o leitor dedicado.

A câmera será exibida aqui.

No APK Android, tocar em Ativar câmera abre captura nativa a cada cinco segundos. Pelo navegador HTTP, utilize a foto manual.

LEITOR PRIVADO

Cartas ocultas da automa

Use uma caixa de leitura opaca, com a carta voltada somente para a câmera interna. A face não aparece no controlador. Este modo necessita de IA configurada.

Coloque a câmera dentro da caixa de leitura privada.

A imagem é enviada somente ao servidor e ao serviço de IA configurado; não é salva como foto pública.

Atenção: o dispositivo de leitura ainda mostra a prévia da câmera. Mantenha sua tela fora do campo de visão do jogador humano.
